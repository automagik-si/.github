# Org page art

The images in this folder are composed from Automagik's own brand and character art (the clay
mark, the lockup, the app icon, Genie, the Omni octopus and the Automagik pet), cropped and scaled
from the files in [automagik-si/automagik](https://github.com/automagik-si/automagik), never
redrawn. Apache-2.0, Namastex Labs and the Automagik contributors; the character art carries the
notices of that repository. The headline is set in Manrope (SIL Open Font License 1.1).

- `banner-light.webp`, `banner-dark.webp`: the README banner, 2560 x 800, shown at up to 1280 wide.
- `block-*-light.png`, `block-*-dark.png`: the small tiles in the README table, 144 x 144.
- `avatar.png`: the organisation avatar, 1024 x 1024. `avatar-dark.png` is an alternate.
